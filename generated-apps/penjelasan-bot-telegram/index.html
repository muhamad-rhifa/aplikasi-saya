Sebagai bot pembuat aplikasi web instan (Telegram Web App Generator), sistem dirancang untuk langsung merespons setiap pesan teks yang masuk dengan menghasilkan sebuah aplikasi web yang relevan atau informatif.

Bagaimana cara menggunakannya?

Cukup ketik perintah atau permintaan spesifik untuk membuat aplikasi web yang Anda inginkan. Contoh: "Buat aplikasi to-do list" atau "Buat kalkulator sederhana".
